## 2. How to reproduce every artifact in the paper

```bash
pip install -e ".[dev]"
python -m pytest                                              # 240 tests
python scripts/run_ablation_matrix.py --workers 5             # synthetic Phase 8 matrix
python scripts/run_complexity_benchmark.py                    # Phase 5 scaling
python scripts/inspect_action_genome.py --root data/action_genome   # requires AG annotations
python scripts/run_pilot_ag.py --workers 4                    # requires AG annotations
python scripts/make_paper_artifacts.py                        # tables, figures, numbers.tex
```

Then compile `paper/main.tex` (pdflatex + bibtex; not installed on the audit machine).

## 3. Known deviations from the PRD

1. The pilot (Phase 3) was not run before Phase 4–5 because no AG data were
   available; the team chose to implement V-HPED first. The go/no-go decision is
   still pending.
2. FixedWindow cannot be evaluated by post-hoc threshold sweep (it thresholds the
   best window score but emits the latest score); it is run once per threshold
   in the ablation matrix and excluded from the AG pilot.
3. The predict step of the alive filter was changed on 2026-10-28 from a
   competing-risk approximation to the exact two-state CTMC transition. Results
   with `rebirth_rate = 0` (all reported runs) are identical under both.
